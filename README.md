🔗 **公開URL**: https://7chillgo-tech.github.io/night-namine-aquarium/

## 概要

島の人口がそもそも少なく、既存客の年齢層も固定化しつつある中でリピート客を
獲得したいという課題がありました。夜間営業という新しい体験を用意することで、
今は足が遠のいてしまっている年代層にも、もう一度訪れたいと思ってもらえる施設に
なることを狙いました。

とにかく人をたくさん集める・お金を稼ぐという目的ではなく、日常の中にある少しだけ
特別な体験をアピールしたかったため、映えよりも落ち着いた雰囲気でゆっくり過ごせる
場所であることが伝わるサイト作りを意識しました。夜のイベントサイトに寄りすぎない
よう、温かい色味をメインカラーに取り入れ、親しみやすさをアピールしています。

## こだわったポイント

- **星座線のスクロール演出**:JSはほぼ独学だったため、特にこの実装には苦労しました。
  スクロール量そのものではなく実際の座標をもとに線の進み具合を計算する方式にすることで、
  線がジグザグに振れる区間でも不自然に止まって見えないよう調整しています。線の曲がり具合や
  星の座標も、実際にブラウザで確認しながら何度も微調整しました。
- **HOW TO ENJOYセクションの文字折り返し**:当初はグリッドの列幅が狭く、説明文が想定より
  折り返されてしまう問題がありました。列幅を見直すことで解消しています。
- **配色**:紺×クリームを基調に、彩度を抑えた色味でまとめました。夜のイベントサイトのような
  派手さに寄りすぎないよう、使う色数を増やしすぎないことを意識しています。
